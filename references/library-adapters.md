# Library Adapters

Use this reference to adapt approved open-source UI libraries without weakening Kinetic UI UX Pro rules. Documented libraries are MIT, Apache-2.0, or ISC licensed. Do not copy component source into this repository; link to upstream URLs and generate local code from our own templates.

## Rules Before Adopting

- Our state matrix still applies: default, hover, focus-visible, active, loading, disabled, error, success, empty.
- Our programmatic signalling still applies: `aria-busy`, pre-mounted polite live regions, focus return, reduced motion, and error recovery.
- Our token layer stays canonical. Library tokens/classes map to our CSS custom properties, not the other way around.
- Vendoring is allowed only when the listed license permits it and the redistributed plugin preserves required copyright, license, and NOTICE files.

| [DaisyUI](https://www.npmjs.com/package/daisyui) | Fast Tailwind semantic class styling and themes. | DaisyUI's semantic classes carry no state matrix: hover may exist, loading and empty do not. | [HyperUI](https://hyperui.dev/) | Free copy-paste Tailwind HTML sections for marketing, ecommerce, and simple app surfaces. | Components are mostly markup/CSS; interactive behavior, state machine, loading/error/success/empty, focus management, and reduced-motion are ours. | [Flowbite core](https://flowbite.com/docs/getting-started/license/) | Open-source Tailwind components with optional JS behaviors. | Core components do not complete our state matrix. Do not use Flowbite Pro assets. | Map Flowbite theme config and Tailwind utilities to generated token values. | [Magic UI](https://github.com/magicuidesign/magicui) | Open-source animated React/Tailwind/shadcn-style effects for expressive surfaces. | Treat as marketing/onboarding-only unless motion is essential. Do not keep decorative hardcoded gradients or timings. | MIT (SPDX: MIT) | Yes, with MIT notice, but avoid vendoring effects into product-interface templates unless necessary. |
| [Motion](https://www.npmjs.com/package/motion) | React/JS/Vue animation, layout transitions, gestures, shared elements. | Motion has no automatic reduced-motion handling; `useReducedMotion` or `matchMedia` is still required. | [AutoAnimate](https://www.npmjs.com/package/@formkit/auto-animate) | Lightweight automatic layout animations for add/remove/reorder. | It animates structure changes but does not know intent. Add reduced-motion opt-out, avoid hidden layout shifts, keep aria announcements for inserted/removed content, and do not use it for data-dense motion where near-zero is required. | Configure duration/easing from our motion tokens; disable or shorten under reduced motion. | MIT (SPDX: MIT) | Yes, with MIT notice. Prefer dependency. |
| [React Spring](https://www.react-spring.dev/) | Spring physics, gestures, interruptible UI motion. | Springs do not automatically satisfy reduced motion, state announcements, or performance budgets. We still enforce `useReducedMotion`, transform/opacity-only animation, loading/error/empty states, and no expressive motion in dense product surfaces. | Mirror `templates/motion.css` with spring presets named by token intent; avoid per-component magic numbers. | MIT (SPDX: MIT) | Yes, with MIT notice. Prefer dependency. |
| [Tremor core](https://github.com/tremorlabs/tremor) | Dashboard/chart/table components for React and Tailwind. | Tremor's charts ship without complete empty or error states. Add no-data, filtered-empty, partial-data, stale, permission-denied, loading skeletons, accessible chart summaries, and non-color-only encodings. Dashboards get near-zero motion. | Replace chart colors and Tailwind theme values with our semantic chart tokens. Use generated color ramps and verified contrast. | Apache-2.0 (SPDX: Apache-2.0) | Yes, if Apache-2.0 license and any NOTICE requirements are preserved. Prefer dependency or local regeneration. |
| [Style Dictionary](https://www.npmjs.com/package/style-dictionary) | Cross-platform design-token build pipeline. | It transforms tokens; it does not validate UX states, contrast intent, naming quality, or component conformance. Our semantic token names remain canonical. | Apache-2.0 (SPDX: Apache-2.0) | Yes, if Apache-2.0 license and any NOTICE requirements are preserved. Build tool should usually remain a dev dependency. |
| [Lucide](https://github.com/lucide-icons/lucide) | Consistent open-source icon set across React, Vue, Svelte, Angular, static SVG. | Icons are not labels. Avoid brand-logo assumptions. | Bind size, stroke width, and color to our icon tokens/custom properties. | ISC (SPDX: ISC), with MIT notices for Feather-derived icons | Yes, with ISC and applicable MIT notices preserved. Prefer dependency. |
| [Radix Colors](https://www.radix-ui.com/colors/docs/overview/installation) | Well-structured accessible color scales and aliases for prototyping. | Color scales do not replace our contrast verification, semantic naming, dark-mode pair checks, or APCA/WCAG gates. Do not pick colors by taste without `color_tools.py`/`token_gen.py`. | Can seed primitives, but final semantic tokens must map to our `--surface-*`, `--text-*`, `--border-*`, and role tokens. | MIT (SPDX: MIT) | Yes, with MIT notice. Prefer dependency or generated token extraction. |
| [Open Props](https://www.npmjs.com/package/open-props) | Broad CSS custom-property primitives for sizes, shadows, typography, easings, and media queries. | Open Props is a primitive palette, not a product design system. We still enforce semantic token mapping, state matrix, contrast, reduced motion, density rules, and design-system drift checks. | Either alias Open Props into our semantic vars or ingest it into `.ds-index`; components should consume our semantic tokens. | MIT (SPDX: MIT) | Yes, with MIT notice. Prefer dependency or selective token ingestion. |

## Deliberately Excluded

| Library | Reason |
| --- | --- |
| [Aceternity Pro](https://ui.aceternity.com/licence) | Paid and redistribution-prohibited: source/items cannot be redistributed as stock/source files, marketplace items, or templates. |
| [Flowbite Pro](https://flowbite.com/license/) | Paid and redistribution-prohibited under its EULA; only Flowbite core released code is allowed. |
| [Tailwind Plus](https://tailwindcss.com/plus/license) | Paid and redistribution-prohibited: components/templates/libraries cannot be redistributed separately or used to create competing libraries, builders, themes, or starter kits. |
