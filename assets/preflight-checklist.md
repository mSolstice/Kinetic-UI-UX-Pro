# Preflight Checklist

Run before declaring any interface finished. Items marked ⚙ are machine-checkable via `scripts/`.

## Framing
- [ ] The job is stated in the user's terms, not the feature's name
- [ ] One primary action per view; everything else subordinate
- [ ] Flow has a reverse path and a failure path
- [ ] Success signal named

## States
- [ ] Default · Hover · Focus-visible · Active · Loading · Disabled · Error · Success · Empty
- [ ] Empty distinguished from cleared-by-filter
- [ ] Slow (>5s) acknowledged with cancel
- [ ] Hostile test data passes: diacritics, CJK, 200-char strings, zero, negative, null, 1-item list

## Accessibility
- [ ] ⚙ No `div` with `onClick`; no positive tabindex; no bare `outline: none`
- [ ] Native element used where one exists (`<dialog>`, `<button>`, `<details>`)
- [ ] ⚙ `aria-busy` fires immediately on load start
- [ ] Live region pre-mounted empty; polite/alert not assertive for form errors
- [ ] Live region OR focus shift, not both
- [ ] Focus returns to trigger on overlay close
- [ ] Escape closes innermost layer only
- [ ] Combobox keeps focus on input via `aria-activedescendant`
- [ ] Keyboard-only pass completed end to end

## Motion
- [ ] ⚙ Reduced-motion degradation path exists (not a blank gate)
- [ ] JS-side reduced motion handled if Framer Motion is used
- [ ] ⚙ Only transform/opacity/filter animated
- [ ] ⚙ `will-change` scoped to active interaction
- [ ] No parallax, auto-carousel, or large-area zoom without a gate

## Color & type
- [ ] ⚙ WCAG 2.x AA computed and passing — `color_tools.py contrast`
- [ ] ⚙ APCA Lc computed, not estimated
- [ ] ⚙ OKLCH values gamut-checked
- [ ] forced-colors: structure survives on borders; focus ring visible
- [ ] prefers-contrast and prefers-reduced-transparency handled
- [ ] ⚙ Font overrides computed, never guessed — `font_metrics.py`

## Layout & input
- [ ] ⚙ Logical properties throughout
- [ ] 320px, 200% zoom, 40% text expansion all pass
- [ ] ⚙ No destructive truncation of text that exists nowhere else
- [ ] 44×44px targets, safe-area insets
- [ ] ⚙ Hover gated behind `@media (hover: hover)`

## Forms
- [ ] Real labels, not placeholders; `aria-describedby` on help/errors
- [ ] `autocomplete` tokens present
- [ ] ⚙ `novalidate` when custom validation runs
- [ ] Focus moves to error summary on failed submit

## Performance
- [ ] ⚙ Images have dimensions or aspect-ratio
- [ ] ⚙ Reads batched before writes; no layout read in a loop
- [ ] Skeleton geometry matches resolved content
- [ ] Theme resolved before first paint

## Ethics
- [ ] No confirmshaming, forced continuity, asymmetric friction, fake urgency, preselected upsells
- [ ] Opting out is as easy as opting in
- [ ] Undo preferred over confirm; destructive actions visually distinct

## Close
- [ ] ⚙ `ast_audit.py` run, errors resolved (or `ui_audit.py` fallback)
- [ ] ⚙ Tokens generated by `token_gen.py`, verification exit code 0
- [ ] Receipt written at the correct tier, reporting only what exists
- [ ] Contrast figures marked COMPUTED or TARGET
